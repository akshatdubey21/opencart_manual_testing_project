# OpenCart Manual Testing - Test Plan

## 1. Project Title
OpenCart Manual Testing Project

## 2. Application Under Test
OpenCart

## 3. Application URL
https://demo.opencart.com/

## 4. Objective
The objective of this project is to perform manual testing of the OpenCart application and verify that its major functionalities work as expected.

## 5. Testing Scope

### In Scope
- User Registration
- User Login
- Product Search
- Product Browsing
- Product Details
- Shopping Cart
- Checkout
- User Account
- Logout

### Out of Scope
- Performance Testing
- Security Testing
- Automation Testing
- Source Code Testing

## 6. Testing Type
- Functional Testing
- UI Testing
- Usability Testing
- Compatibility Testing
- Regression Testing
- Smoke Testing
- Sanity Testing

## 7. Test Environment
- Browser: Google Chrome
- Operating System: Windows
- Testing Type: Manual Testing
